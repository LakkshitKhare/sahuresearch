# Laboratory photographs

Place actual laboratory equipment photographs in this folder when available.
Do not use stock images to represent the professor's instruments.

Suggested filenames match the equipment IDs in `src/lib/content.ts`, for
example `potentiostat.jpg`, `smartpot.jpg`, and `pem.jpg`.

The gallery currently displays clearly labelled SVG schematics. Equipment
photos need to be connected in `src/components/EquipmentFigures.tsx` before
they appear in the gallery. Adding files here alone does not replace those
schematics.

This README preserves the folder in project exports and version control.
